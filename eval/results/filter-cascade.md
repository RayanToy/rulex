# Нужен ли платный фильтр реальности

Пайплайн отсеивал мусор корпуса батч-проверкой через LLM. Вопрос: а нужна
ли она, если есть словари?

## Словарная проверка против модели

На размеченном наборе из 30 слов (`eval/words.tsv`), положительный класс —
`artifact`:

| Фильтр | precision | recall | F1 | accuracy |
|---|---|---|---|---|
| Эвристики (гласные, буквосочетания) | 0.00 | 0.00 | 0.00 | 0.60 |
| **Словарь pymorphy3 (`word_is_known`)** | 0.77 | **0.91** | **0.83** | 0.87 |
| LLM-фильтр (замеры по шести моделям) | 0.55–0.75 | 0.91–1.00 | 0.74–0.83 | — |

Бесплатная словарная проверка не уступает модели ни по recall, ни по F1.

## Где методы расходятся

Чтобы не размечать сотни слов вручную, взята стратифицированная 50/50
выборка из 220 слов (`eval/filter_agreement_words.tsv`) — специально
нацеленная на границу словарной проверки, иначе она решалась бы тривиально.
Размечались только разногласия.

**Согласие: 179/220 = 81.4%.** Из 41 расхождения:

- *LLM считает реальным, словарь не знает* (19 слов) — модель в основном
  права: `парааминосалициловый` (это ПАСК), `оружничий`, `седиментировать`,
  `карбамидный`, `непрямолинейность`. Настоящие слова, просто составные,
  технические или устаревшие.
- *словарь знает, LLM отверг* (22 слова) — здесь чаще ошибается модель:
  `талидомид`, `седок`, `жульен`, `фораминифер`, `растаман` — совершенно
  обычные слова. Остальное — географические прилагательные (`судетский`,
  `тивериадский`), их надо отсеивать, но на другом шаге пайплайна.

Вывод: методы дополняют друг друга, но модель заметно охотнее выбрасывает
настоящие слова.

## Что сделано

Каскад: сначала словари, в модель уходит только то, что они не подтвердили.

| класс | слов | подтверждено словарями |
|---|---|---|
| 2 | 19 869 | 92 % |
| 5 | 25 821 | 64 % |
| 8 | 11 133 | 45 % |
| 11 | 3 734 | 37 % |
| **всего** | **117 250** | **61 %** |

Батч-вызовов на проверку реальности: **3909 → 1521**, то есть на 61 % меньше.
Раньше через один словарь Шарова экономилось 37 %.

Каскад безопасен по построению: словарного подтверждения достаточно, потому
что мусора в словарях нет — пропустить артефакт он не может, только сэкономить
вызов на заведомо реальном слове. Известное исключение — словоформы вместо
лемм (`фельдшеров`): словарь их знает справедливо, но это дефект корпуса,
а не фильтра.
